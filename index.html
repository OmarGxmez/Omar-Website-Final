Course Reflection

The enrollment of CSIS 1430 has been a critical milestone in my journey of developing my practical front-end engineering skillset. I’ve transitioned from basic HTML layouts and CSS styling to responsive design, complex JS logic, and modern UI frameworks such as Bootstrap. I'm creating this portfolio to connect the dots from building multi-page sites to deploying live environments with GitHub. This course has increased my confidence in debugging code, independently researching technical documentation and developing sleek, user-friendly web interfaces.
